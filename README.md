# مظلات وسواتر الرياض

موقع Laravel Monolith عربي وRTL موجه للبحث المحلي والتحويل إلى اتصال أو واتساب داخل مدينة الرياض. جميع الصفحات العامة مبنية بـBlade وتصل إلى المتصفح كـHTML صادر من الخادم. تستخدم لوحة الإدارة Livewire، والتصميم Tailwind CSS، والحركات المهمة فقط GSAP.

## المتطلبات

- PHP 8.3 أو أحدث مع إضافات MySQL وMbstring وFileinfo وGD ودعم WebP. يُنصح بدعم AVIF لتوليد الصيغتين معًا.
- Composer 2.
- Node.js 20 أو أحدث.
- MySQL 8.
- Redis للإنتاج. يعمل التطوير محليًا باستخدام database cache/queue كما في `.env` الحالية.

## تشغيل محلي

```bash
composer install
cp .env.example .env
php artisan key:generate
```

للتطوير السريع يمكن ضبط `DB_CONNECTION=sqlite` وإنشاء `database/database.sqlite`، أو إدخال بيانات MySQL في `.env`. بعد ذلك:

```bash
php artisan migrate --seed
php artisan storage:link
npm install
npm run build
composer run dev
```

## إنشاء حساب المدير

لا يحتوي المشروع على كلمة مرور افتراضية. أضف القيم التالية في `.env` قبل تشغيل الـseeder:

```dotenv
ADMIN_NAME="مدير الموقع"
ADMIN_EMAIL="admin@example.com"
ADMIN_PASSWORD="كلمة مرور طويلة وفريدة"
```

ثم شغّل:

```bash
php artisan db:seed
```

صفحة الدخول: `/admin/login`.

## ما يمكن إدارته

- بيانات النشاط الرسمية المستخدمة تلقائيًا في الهيدر والفوتر والاتصال وواتساب وSchema.
- تصنيفات الخدمات والخدمات والخامات والأسعار المنشورة.
- مناطق الخدمة والمشاريع الحقيقية وصورها.
- عناصر شريط الثقة والخدمات الأكثر طلبًا؛ لا تظهر أرقام أو ادعاءات قبل إضافتها واعتمادها.
- حالات صور المشاريع: معرض، غلاف، قبل، وبعد. تُولّد عند الرفع نسخ WebP وAVIF متجاوبة حتى عرض 1600 بكسل.
- تصنيفات الدليل والمقالات والأسئلة والعلاقات بينها.
- الآراء الموثقة؛ لا تظهر قبل الاعتماد.
- طلبات العملاء وحالتها.
- التحويلات 301 وبيانات SEO المخصصة.

تبدأ إضافة الخدمة أو المشروع أو المقال بالعنوان والوصف والتصنيف والصور والمنطقة وحالة النشر. يقترح المحرر تلقائيًا Slug وMeta Title وMeta Description والكلمة المستهدفة الداخلية والعبارات المرتبطة وOpen Graph وAlt/Caption وCanonical والروابط الداخلية وSchema. تبقى هذه القيم داخل قسم «إعدادات SEO المتقدمة» الاختياري، ولا ينتج الموقع وسم `meta keywords`.

يدعم صندوق الطلبات الحالات: جديد، تم التواصل، معاينة، عرض سعر، تم الاتفاق، ومغلق. صور الموقع المرفوعة تبقى على القرص الخاص، ولا يمكن تنزيلها إلا لحساب مدير. يتضمن النموذج Honeypot وRate Limiting وCSRF والتحقق من نوع الصور وحجمها وأبعادها.

## بيانات الإطلاق وحالات النشر

تعمل Seeders الإطلاق بترتيب واضح: إعدادات النشاط، الخامات، تصنيفات الخدمات والخدمات، مناطق الخدمة، ثم مقالات الدليل. يمكن تشغيلها أكثر من مرة من دون إنشاء سجلات مكررة، ولا تستبدل النصوص التي عُدلت لاحقًا من لوحة التحكم.

- تُنشأ الخدمات الستون بحالة `draft` ومن دون تاريخ نشر أو سعر منشور. نشر الخدمة قرار صريح من محرر الخدمة في لوحة الإدارة.
- عند اختيار `published` يضبط المحرر تاريخ النشر إن كان فارغًا، وعند العودة إلى `draft` يزيله من الصفحات العامة وخريطة الموقع.
- حقول السعر تبقى فارغة، ولا تقبل اللوحة تفعيل «نشر السعر» قبل إدخال سعر بداية معتمد.
- وسط الرياض هو الموقع الأساسي والمنطقة الوحيدة المنشورة أوليًا. بقية المناطق مسودات وتحمل `noindex,follow` إلى أن يتوفر مشروع حقيقي أو محتوى محلي أصلي.
- مقالات الإطلاق العشرة مسودات جاهزة للمراجعة والتحرير قبل النشر.

يمكن تشغيل بيانات الإطلاق عبر:

```bash
php artisan db:seed
```

تولّد النماذج Slugs عربية نظيفة وفريدة. عند تعديل slug منشور يُحفظ المسار السابق تلقائيًا كتحويل 301.

## الإنتاج

اضبط MySQL وRedis و`APP_URL` و`APP_ENV=production` و`APP_DEBUG=false`. استخدم Queue Worker دائم لـ`redis`، ثم نفّذ:

```bash
composer install --no-dev --optimize-autoloader
php artisan migrate --force
php artisan storage:link
npm ci
npm run build
php artisan optimize
```

يجب أن يكون Document Root هو مجلد `public` فقط. عند وضع Cloudflare أمام الخادم، اقفل الوصول المباشر إلى الأصل واضبط عناوين البروكسي الموثوقة في `TRUSTED_PROXIES`. تجاوز كاش HTML للمسارات `/admin*` و`/livewire*` و`/طلبات` وصفحتي `/طلب-معاينة` و`/تواصل-معنا`، ولا تكاش الاستجابات التي تحمل Cookie جلسة. يمكن كاش الأصول المبنية والصور لمدة طويلة مع احترام أسماء الملفات الموقعة من Vite.

للنشر على المسار الحالي `https://test-node.nicebox-sa.com/booking` استخدم [.env.production.example](.env.production.example) واقرأ [دليل Hostinger](docs/DEPLOYMENT_HOSTINGER.md). سكربت النشر لا يستبدل جذر النطاق؛ يستهدف `public_html/booking` فقط ويحتفظ بنسخة قابلة للاستعادة من محتواه السابق.
